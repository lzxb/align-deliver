# MR 描述模板

提交 MR 和补交待交付 MR 都用这一份。各节顺序固定；“批次”只在批次 > 1 时填写，“截图”和“范围外建议”有才写。

````markdown
## 目标

<一句话目标；用户已明确目标时，写其原文>

完成标准：<可验证的标准>

## 核心原则

1. 围绕目标讨论原则，按原则决策，不打补丁
2. 不主动扩大需求范围
3. 不越层修改
4. ……（完整列出 8 条核心原则，保留编号与语义，正文自包含；不复制本机路径或技能内部相对链接）

## 任务原则

1. <对齐时确认的任务原则>
2. <过程中新增的原则>（过程中新增）

## 批次

| 批次 | 一句话 | 边界 | 状态 |
|---|---|---|---|
| 1 | <做什么> | <含什么，不含什么> | 已合并 |
| **2** | **<做什么>** | **<含什么，不含什么>** | **本 MR** |
| 3 | <做什么> | <含什么，不含什么> | 待做 |

依赖：<本批依赖的前序合并请求链接；不依赖则写“无”>

## 决策说明

### 决策 1：<决策>

- 依据：原则 <N>
- 理由：<为什么>
- 放弃的方案：<方案，以及放弃的原因>

改动前：

```

| 轮次/检查 | 结论 | 修改文件 | 证据 |
|---|---|---|---|
| 第 1 轮 | <如：发现 3 处违反任务原则 2> | 4 | 读代码 |
| 第 2 轮 | <如：修复后复查 1 处> | 1 | 实测 |
| **第 3 轮** | **无问题** | **0** | **实测** |
| lint / 类型检查 / 测试 | <结果> | — | 实测 |

## 后续维护

<本任务有可推进工作时先做；已提交 MR 且暂无可推进工作时，创建/复用一个任务级定时任务。>

- 本次交付：<当前源分支 → 目标分支；复用开放 MR / 首次创建 / 承接已终态 MR 的新增差异；如有前序 MR，说明其实际终态>
- 范围：<本任务全部 MR 与未提交/待建 MR/待恢复工作，不只当前 MR>
- 新增提交：每次 commit / push / MR 写入前核对当前分支关联；开放则续更，终态后有已授权有效差异则从最新上游建新分支、新 MR，重新验收并加入同一任务维护。无差异不建空 MR，关闭/取消的范围不自动重做；未知或失败先查真实结果再恢复。
- 检查：<用户时区，周一至周五 09:00—21:00，每 30 分钟，含 21:00>
- 当前状态：<未到创建时机 / 已创建并核实 / 待恢复；仅已核实后填写生效与下次运行时间，不复制本机台账路径>
- 结束条件：全部 MR 已确认合并、关闭或取消，且无遗漏工作；单个 MR 结束或查询失败不取消任务。
````

## 填写要求

- 核心原则完整保留编号与语义，不按本任务增删或改变规则；正文必须能独立理解，不机械照抄技能内部路径或相对链接。本任务怎么理解写进任务原则或决策说明。
- 路径用于定位文件，不替代必要说明。技能中对其他文档的要求，生成 MR 时写成正文中的具体规则；只把路径改成代码样式仍不足以让读者理解。
- 确需引用文件时，使用仓库中已核对的网页链接，优先固定到提交。提交、更新或补交 MR 前，核对实际目标文件、访问权限与锚点；无法验证的引用不用作依据，改为内联必要内容，不猜测或编造 URL。
- 一个决策对应一组“改动前 → 改动后”，多个决策分开列。前后两段用同一个输入，展示决策带来的结果变化，不是只贴改动后的代码写法。
- 最小示例只保留决策影响的几行；一眼看不出差别，说明决策还没讲清楚。
- 批次表沿用台账中已确认的批次与边界，只更新真实状态，本 MR 所在行加粗；终态后新增交付先在台账登记承接关系，不伪造批次或改写旧 MR 结果。
- 验收证据表的最后一轮必须是 0 修改；每一轮的结论都写明发现的问题违反了哪条原则（如“违反任务原则 2”），说不出违反哪条原则的修改，就不该改。
- 每个决策都写“依据：原则 N”；原则缺失或冲突时新增的原则，在任务原则里标注“过程中新增”。
- CI 失败不是本 MR 引起的，不扩大范围修复；在 CI 行附证据，保持阻塞/待恢复，不记为绿灯。待运行或未知也不能填“实测通过”。
- 后续维护如实填写调度实际状态；没有可推进工作才创建一个覆盖全任务的定时任务，不能按 MR 重复创建。定时维护不自动合并、关闭或取消 MR。
- 新分支的新 MR 只描述尚未交付的有效差异；前序已合并 MR 可作背景，不能仍写成待合并依赖。创建成功即加入原任务台账，CI 未通过也不可遗漏；新分支待交付时不能因旧 MR 全部终态而取消维护。
- 汇报分别使用已提交待处理、待恢复、已合并、已关闭、已取消；不把关闭/取消或一轮检查结束写成目标成功。
